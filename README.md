## 📌 Tentang Proyek

**SIROBOT Website** merupakan platform digital yang dikembangkan untuk mendukung kebutuhan informasi dan publikasi Unit Kegiatan Mahasiswa (UKM) Robotika.

Website ini dirancang sebagai media informasi yang memudahkan mahasiswa dan masyarakat dalam mengenal organisasi, mengetahui kegiatan, mengakses materi edukasi, serta memperoleh informasi pendaftaran anggota baru.

### 🎯 Tujuan Pengembangan

- Meningkatkan aksesibilitas informasi organisasi.
- Menyediakan pusat dokumentasi kegiatan dan prestasi.
- Memfasilitasi publikasi berita dan informasi terbaru.
- Menyediakan repositori modul edukasi dan diklat.
- Mempermudah proses informasi dan pendaftaran anggota baru.

## 🚀 Instalasi dan Menjalankan Proyek

### 1. Clone Repository

```bash
git clone https://github.com/niccowibowo/SIROBOT-WDA.git
```

### 2. Masuk ke Direktori

```bash
cd SIROBOT
```

### 3. Buka Proyek

Buka folder proyek menggunakan Visual Studio Code.

```bash
code .
```

### 4. Jalankan Website

Gunakan ekstensi **Live Server** pada Visual Studio Code, kemudian buka file `index.html` melalui Live Server.

## 🔄 Panduan Kolaborasi Git

Proyek ini menggunakan GitHub sebagai media kolaborasi dan pengelolaan versi kode.

### Mengambil Perubahan Terbaru

```bash
git pull origin main
```

### Membuat Branch Baru

```bash
git checkout -b nama-branch
```

### Menambahkan Perubahan

```bash
git add .
git commit -m "deskripsi perubahan"
git push origin nama-branch
```

### Berpindah Branch

```bash
git checkout main
```

**Ketentuan kolaborasi:**

1. Selalu lakukan `git pull` sebelum mulai mengerjakan proyek.
2. Gunakan branch masing-masing untuk pengembangan fitur.
3. Gunakan commit message yang jelas dan deskriptif.
4. Lakukan pemeriksaan kode sebelum menggabungkan perubahan.
5. Hindari mengubah file yang sedang dikerjakan anggota lain tanpa koordinasi.
